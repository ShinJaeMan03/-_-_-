# 🌊 시추주상도 기반 토질 액상화 예비평가 프로그램

시추주상도(PDF, 이미지) 및 시추조사 입력 자료(Excel, CSV)를 분석하여 **지반의 토질 액상화(Liquefaction) 발생 가능성 및 본평가 대상 여부를 자동으로 판정하는 GUI 프로그램**입니다.

---

## 📌 주요 기능 (Features)

1. **시추주상도 이미지 및 PDF 자동 분석 / 미리보기**
   - PDF/이미지 형태의 시추주상도를 첨부하고 마우스 휠 및 드래그로 손쉽게 확대/축소하여 확인.
   - `PyMuPDF` 및 `Tesseract OCR` 기반으로 텍스트, 지하수위, 시추번호, 좌표, 표고, SPT-N값 자동 추출 지원.

2. **자동 의존성 안내 및 원클릭 설치 지원**
   - 필수 패키지(`PyMuPDF`, `Pillow`, `pytesseract`, `openpyxl`) 미설치 시 프로그램 내부에서 클릭 한 번으로 자동 설치 진행.
   - 설치 없이도 CSV 불러오기 및 수기 입력으로 예비평가 수행 가능.

3. **지층별/심도별 액상화 예비평가 자동화**
   - **평가 기준**:
     - 연중 최고지하수위 하부 위치 여부
     - 지반 심도 20m 이내 여부
     - 표준관입시험 타격횟수 N <= 25 여부
     - 사질토(모래, 실트질 등) 지반 여부 (암반 및 풍화암은 제외)
   - 굴진심도 및 N값 측정 개수에 맞춰 측점 간격(1.0m 또는 1.5m) 자동 산정 및 관입불가(50/5, 1/50 등) 시 기반암 자동 판정.
   - 지하수위 등 일부 정보가 누락된 경우에도 **부분자료 예비평가** 모드로 유연한 평가 진행.

4. **평가 기록 관리 및 저장/비교 기능**
   - 수행된 모든 평가 이력을 자동 기록 저장 (`liquefaction_history.json`).
   - 서로 다른 두 시추주상도의 평가 결과를 지층/심도별로 정밀 비교 및 다중 탭 Excel 파일 저장 지원.
   - 결과를 클립보드로 복사하여 Excel 등에 즉시 붙여넣기 기능 제공.

## 1. 개발 배경 및 개요

- **액상화 현상**: 포화된 느슨한 사질토 지반에 지진동과 같은 동적 하중이 작용할 때 과잉간극수압이 증가하여 유효응력이 0이 되고 전단강도를 상실하여 액체처럼 거동하는 현상입니다.
- **개발 목적**: 지반 조사 시 작성되는 시추주상도 이미지/PDF 또는 수기 입력 자료에서 최고지하수위, 심도별 SPT-N값, 지반 종류, 좌표, 표고, 케이싱 심도 등을 자동으로 읽어 들여 **액상화 본평가 수행 필요 여부(예비평가 판정)**를 신속하고 정확하게 판정하기 위해 개발되었습니다.

## 2. 주요 기능 및 판정 기준

### 1) 엄격한 전체 판정 규칙 (예비평가 제외 우선)
- 조사 측점 중 **'예비평가 제외' 조건에 해당하는 측점이 단 하나라도 존재하면, 전체 예비평가 판정을 '예비평가 제외'로 산정**합니다.
- **모든 측점이 예비평가 대상 조건을 충족할 때만** 전체 결과가 '예비평가 대상'으로 최종 확정됩니다.

### 2) 측점별 예비평가 4대 평가 기준
1. **지하수위 조건**: 연중 최고지하수위 하부 지층 (`심도 >= 최고지하수위 심도`)
2. **심도 조건**: 지표면 이하 20m 이내 (`GL- <= 20.0m`)
3. **N값 조건**: 표준관입시험 원시 타격횟수 `N <= 25` (낙하횟수 보정 전 원시 타격값 기준)
4. **지반 조건**: 모래/사질토 지층 (암반, 기반암, 자갈, 점토층 제외)

### 3) 굴진심도 기반 SPT 측점 간격(1.0m / 1.5m) 자동 추정
- 시추주상도의 굴진심도(측정종료심도)와 SPT 측정 개수를 비교하여 **측점 간격이 1.0m인지 1.5m인지 자동으로 판단**하고 심도를 산정합니다.
- 관입불가 표기(예: `50/5`, `1/50`, `50/19` 등)가 나오는 시점부터는 이후 지층을 기반암으로 처리하여 과도한 심도 평가를 방지합니다.

### 4) OCR / PDF 자동 파싱 및 정보 확장
- PDF 문서(`PyMuPDF`) 및 이미지 파일(`Pillow`, `Tesseract OCR`)에서 텍스트 및 메타데이터 자동 추출
- **파싱 항목**: 시추번호, 조사명, 위치, 표고(m), **좌표 X(N)**, **좌표 Y(E)**, **케이싱 심도(-m)**, 최고지하수위 심도(m), SPT 측정종료심도(m), 심도별 SPT-N 표기

### 5) 지표면 표고 - 심도 실시간 자동 연동
- 상단 기본 정보의 **지표면 표고(m)**나 측점별 **심도(GL-, m)**가 추가·수정되면, 측점별 표고(`지표면 표고 - 심도`)를 실시간으로 자동 재계산합니다.

### 6) 전 탭 시추주상도 Canvas 미리보기 연동
- **'시추자료 입력'** 탭 및 **'파일 자동 읽기'** 탭 우측에 시추주상도 Canvas 미리보기 뷰어를 동시에 제공하여 PDF/이미지 파일 첨부 시 주상도를 즉시 확인할 수 있습니다.
- 마우스 휠을 통한 확대/축소(Zoom) 및 마우스 드래그 이동을 지원합니다.

### 7) 히스토리 관리 및 기록 비교 내보내기
- 평가 결과 및 메타데이터를 `liquefaction_history.json` 파일에 자동 보관하며, 즐겨찾기(★) 및 삭제 기능을 제공합니다.
- **두 기록 비교 기능**: 저장된 이전 평가 기록 2개를 선택하여 지층별·측점별 판정 차이를 대조하고 비교 결과를 Excel(`.xlsx`) 파일로 내보낼 수 있습니다.

## 4. 필요한 환경 및 라이브러리

- **Python**: 3.8 이상
